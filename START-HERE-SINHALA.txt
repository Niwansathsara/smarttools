LOGIN / SIGNUP / ADMIN සකස් කිරීම
--------------------------------
Firebase නැතුව account features ක්‍රියාත්මක වෙන්නේ නැහැ. ඒවා ආරක්ෂිතව සකස් කිරීමට:

1. https://console.firebase.google.com/ වෙත ගිහින් Firebase project එකක් හදන්න.
2. Authentication → Sign-in method → Email/Password Enable කරන්න.
3. Firestore Database එකක් Create කරන්න.
4. Firebase Web App config එක copy කරන්න.
5. assets/js/firebase-config.js file එක open කර apiKey, authDomain, projectId, appId හිස් තැන්වල Firebase values දාන්න.
6. Admin account එකක් ලෙස niwansathsara76@gmail.com ලියාපදිංචි කර, Firebase එකෙන් එන verification email එකෙන් verify කරන්න.
7. firestore.rules file එකේ rules Firebase Console → Firestore → Rules තුළ paste කර Publish කරන්න.
8. Firebase Authentication → Settings → Authorized domains තුළ ඔයාගේ live website domain එක Add කරන්න.

Admin Dashboard එකෙන් දැනට Homepage Latest Updates publish / delete කරන්න පුළුවන්. Firestore Rules වලින් verified admin email එකට පමණක් write permission දෙයි. Public visitors ලාට website එකේ tools භාවිතා කරන්න පුළුවන්; login අනිවාර්ය නැහැ.
