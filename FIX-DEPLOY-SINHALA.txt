SMARTTOOLS – GitHub Pages upload fix
====================================

ඔයාට කලින් පෙන්වූ screenshot එකේ CSS සහ JavaScript load නොවීම නිසා website එක plain text ලෙස පෙනෙනවා.
මෙම ZIP එක GitHub Pages සඳහා සකස් කර ඇත. ZIP එකේ ඇතුළත index.html, assets/ සහ tools/ එකම root මට්ටමේ ඇත.

කරන්න ඕන දේ:
1. මේ ZIP එක Download කර Extract කරන්න.
2. Extract කළ folder එක open කරන්න.
3. ඒ folder එක ඇතුළේ ඇති සියලුම files සහ folders select කරන්න (index.html, assets, tools, about.html, ...).
4. GitHub → niwansathsara/smart-tools repository → Code වෙත යන්න.
5. Add file → Upload files තෝරන්න.
6. Extract කළ folder එක ඇතුළේ ඇති සියලුම දේ drag-and-drop කරන්න. ZIP file එකම upload කරන්න එපා. smarttools-github-pages නමැති පිටත folder එක හෝ වෙනත් folder එකක් repository ඇතුළට දාන්න එපා.
7. Repository root එකේ index.html සමඟම assets/ සහ tools/ folders පෙනෙන බව තහවුරු කරන්න.
8. Commit changes කරන්න.
9. GitHub repository → Settings → Pages වෙත ගොස් Branch = main සහ Folder = /(root) තෝරා Save කරන්න (දැනටමත් එසේ නම් වෙනස් කරන්න අවශ්‍ය නැහැ).
10. Deploy වුණාට පසු Ctrl + F5 කරලා website එක refresh කරන්න.
